# Mr.-OL-English

Teacher Ouch Ol - English & ICT Educator Portfolio & Interactive Learning Hub.

## 🌟 About
Online Portfolio and Interactive Learning Platform for Hun Sen Svay Thom High School students and educators.

## 🚀 Features
- **Online Tests Hub**: Grade 10 English interactive quizzes & Bloom taxonomy assessments.
- **Educational Games**: Hangman Full Arena, Word Shake II vocabulary challenge.
- **Teaching Resources & Curriculum**: Lesson plans, digital books, and multimedia resources.
- **Professional CV**: Educator profile, certifications, and teaching journey.
